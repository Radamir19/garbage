# Todo: навигация и удаление задач

## Запуск

Нужны Flutter 3.35.7 или новее и Chrome. В терминале откройте папку с `pubspec.yaml`:

```sh
flutter --version
flutter pub get
flutter run -d chrome
```

Если команда `flutter` не найдена, установите Flutter SDK и добавьте его папку `bin` в PATH. Проверить установку можно командой `flutter doctor`.

## Проверка

```sh
flutter analyze
flutter test
flutter test test/package_check.dart test/behavior_check.dart
```

Последняя команда явно запускает проверку пакета и все сценарии задания. Эти файлы не заканчиваются на `_test.dart`, поэтому обычный `flutter test` их автоматически не запускает.

## Что сделано

Весь код приложения находится в `lib/main.dart`.

- Список задач и кнопка «Добавить». Новая задача возвращается из второго экрана через `Navigator.pop<String>`, принимается после `await Navigator.push<String>` и добавляется через `setState`.
- Форма с полем «Название». Перед сохранением вызывается `trim()`. Пустой ввод показывает «Введите название», Back закрывает форму без добавления.
- `flutter_slidable` 4.0.3 добавлен в `pubspec.yaml` и `pubspec.lock`. Свайп справа налево показывает кнопку «Удалить», но сам ничего не удаляет.
- Нажатие «Удалить» открывает диалог с названием задачи. Подтверждение возвращает `true`, отмена — `false`, закрытие без ответа — `null`. Удаление происходит только при `true` и по id, поэтому одинаковые названия не мешают.
- После ожидания маршрута и диалога проверяется `mounted`. Поле освобождает контроллер в `dispose`. Форма прокручивается при открытой клавиатуре; кнопка добавления находится под списком.

Данные хранятся в памяти. После полного перезапуска снова появляются две исходные задачи. При пустом списке отображается «Пока нет задач».

## Ручная проверка

1. Добавить задачу с пробелами по краям: в списке должно быть обрезанное название.
2. Попробовать сохранить пробелы, затем исправить ввод. Проверить Back без сохранения.
3. Сделать свайп, открыть диалог, отменить. Повторить и подтвердить удаление.
4. Добавить две задачи с одинаковыми названиями и удалить одну.
5. Удалить все задачи, затем добавить новую.
6. Проверить форму при ширине окна 320 px и с открытой клавиатурой.

## Статус проверки

В облачной среде нет Flutter SDK, а его загрузка с `storage.googleapis.com` заблокирована сетевой политикой (403). Поэтому `flutter pub get`, анализатор, тесты и сборка здесь не запускались. Зависимость и её контрольная сумма взяты из официального API pub.dev; архив пакета проверен по SHA-256. Lock-файл дополнен этими данными вручную, его разрешение нужно подтвердить командой `flutter pub get`.

Исходные тесты сохранены без изменений. Картинки в `docs/screenshots` — макет из задания, а не снимки выполненного приложения. Для сдачи по исходному заданию также нужны результаты самопроверки, собственные скриншоты двух экранов и диалога, короткое видео добавления, отмены и удаления, ссылка на репозиторий и commit.
